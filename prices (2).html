Стоимость услуг по моделям

Строки — единый набор услуг. Каждый вертикальный столбец — отдельная модель автомобиля. В пересечении укажите стоимость услуги для этой модели.
Пустая цена = услуга не предлагается / цена не заданаВсе изменения попадут в калькулятор после кнопки «Сохранить»
Как заполнять: добавьте нужные модели столбцами → при необходимости дополните список услуг → внесите цены по пересечениям → нажмите «Сохранить». Название услуги задается один раз и используется для всех моделей.
